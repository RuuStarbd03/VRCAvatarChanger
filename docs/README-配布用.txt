VRCAvatarChanger
================

VRChat を開かずにアバターを着替えられる Windows 用アプリです。
VRChat を起動中なら、すぐにゲーム内のアバターも切り替わります。


■ 使い方

  1. VRCAvatarChanger.exe をダブルクリックします。インストールは不要です。
     (「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」)

  2. VRChat のアカウントでログインします。
     ユーザー名とパスワード、または「ふだん使うブラウザでログイン」から。
     (ブラウザで VRChat にログイン済みなら、表示された token をコピーするだけです)
     パスワードはこのアプリには保存されません。

  3. 一覧からアバターを選んで「選択したアバターに着替える」を押すか、
     アバターをダブルクリックします。

  詳しい説明とよくある質問は、アプリ右上の「使い方」(F1)にあります。


■ できること

  ・自分のアバター / お気に入り / パブリック のタブから着替え
  ・右クリックからお気に入りへの登録・解除(グループを選べます)
  ・「パブリック」は、気に入ったパブリックアバターを上限なく登録できる独自リスト
  ・衣装違いなどを「グループ」にまとめる(ドラッグ&ドロップ)
  ・リスト表示 / ボックス表示、並び順、検索
  ・「直前に戻す」で、1 つ前に着ていたアバターへ戻る
  ・VRChat のプレイ中に使えるホットキー(既定は Shift+1 でアバター選択。設定で変更・追加できます)
  ・VRChat の OSC を有効にしておくと、着替えが即座に反映され、ゲーム内で着替えたときも表示が追従


■ 安全について

  ・保存するのはログイン状態(暗号化)・表示設定・パブリックリスト・グループと、
    表示を速くするための一覧とサムネイルの控えだけです。
    保存先: %AppData%\VRCAvatarChanger
  ・通信先は VRChat のサーバーだけです。
  ・「ふだん使うブラウザでログイン」で受け取るのは、あなたがコピーした token だけです。
    Chrome などに保存されたパスワードやクッキーを読むことはありません。
  ・「アプリ内ブラウザでログイン」を使うと、内蔵ブラウザに VRChat・Discord・Google の
    ログイン状態が残り、次回のログインが数クリックで済みます
    (設定「ブラウザのログイン状態を保持」でオフにできます)。
  ・ログイン状態はアカウント全体を操作できるものです。
    共用 PC では「保持」をオフにし、使い終わったら右上の「設定」→「ログアウト」を押してください。


■ アンインストール

  exe(または解凍したフォルダ)を削除するだけです。
  保存データも消す場合は %AppData%\VRCAvatarChanger フォルダを削除してください。


■ 注意

  VRChat 公式のアプリではありません。VRChat の仕様変更で動かなくなることがあります。
